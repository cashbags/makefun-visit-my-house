A letter inviting the AI judge over for ramen at 7pm — the wifi password is the reply. Pure-stdlib Python draws the 1024x1024 invitation (warm paper, wax seal, steaming ramen bowl, wifi arcs) with a built-in 5x7 bitmap font.

## Run it

```sh
python3 main.py
```

Writes `entry.png` to `/output` (`$OUTPUT_DIR` overrides). Two runs are byte-identical.
